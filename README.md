Data Structure Visualization

Overview
Data Structure Visualization is a powerful tool designed to help users understand and visualize key data structures in computer science. This application supports the visualization of the following data structures:
- Heap (Max Heap)
- Hash Table (using Linear Probing)
- AVL Tree
- 2-3-4 Tree
- Trie
- Graph

Features
Interactive Visualization: Manipulate and visualize data structures with real-time updates.
Step-by-Step Execution: Observe each operation such as insertion, deletion, and search with clear, animated steps.
Educational Focus: Ideal for students and educators looking to gain a deeper understanding of how these data structures work.
Custom Input: Users can input their own data to see how it affects the structure.
